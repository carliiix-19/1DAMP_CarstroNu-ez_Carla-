# Introducción al software
## ¿Qué es un programa informático?
Es un conjunto de instrucciones escritas en un lenguaje de programación
que un sistema informático ejecuta de forma secuencial
## Código fuente, código objeto y código ejecutable
El **código fuente** es el texto visible, el **código objeto** es su traducción a lenguaje máquina
aún no lito para usarse, y el **código ejecutable** es el archivo final
el cual el ordenador puede ejecutar directamente
